# 나스닥 100 상관관계 그래프

나스닥 100 종목의 **수익률 상관관계 네트워크**와 **테마 로테이션**을 매일 자동으로 갱신하는 정적 대시보드입니다.

**사이트**: https://eloyyang.github.io/nasdaq100-graph/

## 무엇을 보여주나

| 탭 | 내용 |
|---|---|
| 종목 네트워크 | 최근 1년 일별 수익률의 피어슨 상관계수로 연결한 그래프. 종목 선택 시 상관 종목 순위, 주가 차트, 선행·후행 검증 |
| 테마 사이클 | 5년 테마 지수, 월별 수익률 히트맵, 리더십 전이 행렬, 테마 간 시차 상관 |

좌측 **주도주** 패널은 직전 거래일에 지수를 움직인 종목을 등락률과 지수 기여도(등락률 × 시총 비중) 두 기준으로 보여줍니다.

종목을 선택하면 **펀더멘털**이 함께 열립니다 — PER(TTM), EPS, 목표주가, 52주 범위, 배당, 연간 매출·영업이익·순이익·총부채·현금(전년 대비 증감), 최근 4분기 실적(컨센서스 대비 서프라이즈)과 향후 분기 추정치.

재무 항목을 클릭하면 **연도별 추이 차트**가 펼쳐집니다 — 4년치 막대와 전년 대비 증감률, 누적·연평균 성장률. 실적 섹션을 클릭하면 분기 EPS 차트(실제 막대 + 컨센서스 표시 + 추정 점선)가 열립니다.

봉차트(OHLC)는 축 드래그 확대·이동과 추세선/수평선 그리기를 지원하고, 즐겨찾기는 브라우저에 저장됩니다.

## 자동 갱신

`.github/workflows/update.yml`이 **평일 22:00 UTC(한국시간 다음날 07:00)** 에 실행되어

1. `api.nasdaq.com/api/quote/list-type/nasdaq100` 에서 **그날의 구성종목**을 가져오고
2. 처음 보는 종목은 `summary` 엔드포인트의 Sector/Industry로 **테마를 자동 분류**하고 (`data/sectors.json`에 캐시)
3. 종목마다 5년 일별 OHLCV를 받고, 재무제표·EPS는 하루 25종목씩 순환 갱신하며 (`data/fundamentals.json`)
4. 상관계수·선행후행·로테이션 지표를 다시 계산한 뒤
5. `dist/index.html`을 빌드해 GitHub Pages로 배포합니다.

편입·편출이 생기면 다음 실행에서 자동으로 반영됩니다. 손으로 종목 목록을 고칠 필요가 없습니다.

## 데이터 무결성 장치

- **시세/구성종목 교차검증**: 과거 시세의 마지막 종가가 당일 호가와 25% 이상 어긋나면 다른 종목이 반환된 것으로 보고 Yahoo 데이터로 대체하거나 제외합니다. (Nasdaq API가 특정 심볼을 엉뚱한 종목으로 해석한 사례가 있었습니다)
- **윈저화**: 일간 수익률을 ±25%로 자른 뒤 상관계수를 계산합니다. 분할·분사 같은 1회성 이벤트가 상관계수를 지배하지 못하게 합니다.
- **부분 실패 시 중단**: 종목의 80% 미만만 수집되면 빌드를 실패시켜, 얇은 데이터가 배포되지 않도록 합니다. 이 경우 사이트는 직전 버전을 계속 서비스합니다.

## 직접 빌드

```bash
python3 build/pipeline.py --out dist    # 표준 라이브러리만 사용
open dist/index.html
```

과거 데이터의 통계적 성질을 보여줄 뿐이며 투자 자문이 아닙니다. 상관관계는 인과관계가 아니고, 테마 전이 행렬의 표본은 60개월 남짓이라 개별 칸의 확률은 신뢰하기 어렵습니다.
