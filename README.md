# 글로벌 자산 상관관계 그래프

**나스닥100 · 코스피100 · 주요 미국 ETF · 비트코인/이더리움 · 금**의 수익률 상관관계 네트워크와
**테마 로테이션**을 매일 자동으로 갱신하는 정적 대시보드입니다.

**사이트**: https://eloyyang.github.io/nasdaq100-graph/

## 커버리지

| 자산군 | 종목 수 | 출처 |
|---|---|---|
| 나스닥100 | 102 | `api.nasdaq.com` (구성종목·시세·재무제표) |
| 코스피100 | 99 | `finance.naver.com` (구성종목·시세) |
| 미국 ETF | 19 | SPY·QQQ·DIA 등 지수·섹터·채권·원자재 ETF (`data/assets.json`) |
| 암호화폐 | 2 | 비트코인, 이더리움 |
| 금 | 1 | GLD |

총 **223개 자산**이 하나의 상관계수 네트워크·테마 로테이션에 함께 들어갑니다 — 예를 들어
"코스피가 오르면 나스닥은?", "비트코인은 어떤 종목과 같이 움직이나", "금은 방어 자산 역할을 하고 있나" 같은
질문에 실제 5년치 데이터로 답할 수 있습니다.

## 무엇을 보여주나

| 탭 | 내용 |
|---|---|
| 종목 네트워크 | 최근 1년(계산일 기준 365일) 일별 수익률의 피어슨 상관계수로 연결한 그래프. 종목 선택 시 상관 종목 순위, 주가 차트, 선행·후행 검증 |
| 테마 사이클 | 5년 테마 지수, 월별 수익률 히트맵, 리더십 전이 행렬, 테마 간 시차 상관 (총 12개 테마: 나스닥 8개 + 코스피100·미국ETF·암호화폐·금) |

좌측 **주도주** 패널은 직전 거래일에 **나스닥100 지수**를 움직인 종목을 등락률과 지수 기여도(등락률 × 시총 비중) 두 기준으로 보여줍니다. 코스피/ETF/암호화폐/금을 섞은 "지수"는 의미가 없어(삼성전자+비트코인+애플을 시총가중 평균하는 것과 같으므로) 이 패널은 나스닥100에만 한정됩니다.

종목을 선택하면 원화(₩)/달러($) 등 **통화가 자동으로 맞춰져** 표시됩니다. 나스닥100 종목에는 **펀더멘털**이 함께 열립니다 — PER(TTM), EPS, 목표주가, 52주 범위, 배당, 연간 매출·영업이익·순이익·총부채·현금(전년 대비 증감), 최근 4분기 실적(컨센서스 대비 서프라이즈)과 향후 분기 추정치. (코스피·ETF·암호화폐·금은 Nasdaq의 재무제표/EPS 엔드포인트가 미국 주식 전용이라 펀더멘털 패널이 뜨지 않습니다.)

**성과** 차트는 매출·순이익 막대(우축 금액)와 순마진 % 라인(좌축)을 겹쳐 보여주며, 연간/분기별로 전환됩니다. 범례로 현금성자산·부채 계열을 추가하거나 계열을 숨길 수 있습니다.

**어닝** 차트는 분기·연간 EPS를 점으로 표시합니다 — 채운 점은 발표된 실적, 빈 점은 컨센서스 추정치. 과거 연간 EPS 실적은 Nasdaq이 제공하지 않아 연간 뷰는 최근 12개월(TTM) 실적에 회계연도별 컨센서스를 잇습니다.

개별 재무 항목을 클릭하면 **연도별 추이 차트**가 펼쳐집니다 — 4년치 막대와 전년 대비 증감률, 누적·연평균 성장률. 실적 섹션을 클릭하면 분기 EPS 차트(실제 막대 + 컨센서스 표시 + 추정 점선)가 열립니다.

봉차트(OHLC)는 축 드래그 확대·이동과 추세선/수평선 그리기를 지원하고, 즐겨찾기는 브라우저에 저장됩니다.

## 자동 갱신

`.github/workflows/update.yml`이 **평일 22:00 UTC(한국시간 다음날 07:00)** 에 실행되어

1. **나스닥100**: `api.nasdaq.com/api/quote/list-type/nasdaq100`에서 그날의 구성종목을 가져오고, 처음 보는 종목은 `summary` 엔드포인트의 Sector/Industry로 테마를 자동 분류합니다 (`data/sectors.json`에 캐시).
2. **코스피100**: `finance.naver.com`의 구성종목 페이지(약 10페이지)를 파싱해 종목·시세·시가총액을 가져옵니다. 원화 시가총액은 실시간 환율(`exchangerate-api.com`, 실패 시 1,350원 고정값)로 달러 환산해 노드 크기를 다른 자산과 비교 가능하게 맞춥니다.
3. **ETF/암호화폐/금**: `data/assets.json`에 정의된 고정 목록을 같은 Nasdaq API(`assetclass=etf`/`crypto`)로 가져옵니다. ETF/금은 AUM을 제공하지 않아 최근 60거래일 거래대금 중앙값으로 노드 크기를 근사하고, 암호화폐는 유통량 × 현재가로 실제 시가총액을 계산합니다.
4. 종목마다 5년 일별 OHLCV를 받고, 나스닥100 재무제표·EPS는 하루 25종목씩 순환 갱신하며 (`data/fundamentals.json`)
5. 상관계수·선행후행·로테이션 지표를 **223개 자산 전체**에 대해 다시 계산한 뒤
6. `dist/index.html`을 빌드해 GitHub Pages로 배포합니다.

편입·편출이 생기면 다음 실행에서 자동으로 반영됩니다. 손으로 종목 목록을 고칠 필요가 없습니다.

## 데이터 무결성 장치

- **시세/구성종목 교차검증**: 과거 시세의 마지막 종가가 당일 호가와 25% 이상 어긋나면 다른 종목이 반환된 것으로 보고 Yahoo 데이터로 대체하거나 제외합니다. (Nasdaq API가 특정 심볼을 엉뚱한 종목으로 해석한 사례가 있었습니다)
- **윈저화**: 일간 수익률을 ±25%로 자른 뒤 상관계수를 계산합니다. 분할·분사 같은 1회성 이벤트가 상관계수를 지배하지 못하게 합니다.
- **날짜 기준 1년 창**: 상관계수 네트워크의 "1년"은 거래일 개수(252일)가 아니라 **달력 기준 365일**로 자릅니다. 암호화폐가 주말에도 거래되면서 공유 날짜축이 늘어나, 행 개수 기준으로 잘랐다면 "1년"이 실제로는 8~9개월로 줄어드는 문제가 있었습니다.
- **주도주 지수는 나스닥100 전용**: 서로 다른 자산군을 하나의 "지수"로 시총가중 평균하는 것은 의미가 없으므로, 등락률/지수 기여도 계산은 나스닥100 종목으로만 한정합니다.
- **부분 실패 시 중단**: 종목의 80% 미만만 수집되면 빌드를 실패시켜, 얇은 데이터가 배포되지 않도록 합니다. 이 경우 사이트는 직전 버전을 계속 서비스합니다.

## 직접 빌드

## 한계

과거 데이터의 통계적 성질을 보여줄 뿐이며 투자 자문이 아닙니다. 상관관계는 인과관계가 아니고, 테마 전이 행렬의 표본은 60개월 남짓이라 개별 칸의 확률은 신뢰하기 어렵습니다. 원화·달러 등 서로 다른 통화로 표시된 자산 간 상관계수는 환율 변동분이 섞여 있으며 별도로 제거하지 않았습니다 — 원화 기준 수익률 그대로 사용합니다.
